FitTrack Platform

Precision tracking for workouts, hydration, sleep, and long-term goals.

Built on a Java 17 object-oriented backend with SQLite JDBC persistence, PBKDF2 authentication, and real-time analytics.

  • Eight polymorphic workout classes with MET calorie computation
  • Weekly Mon–Sun workout planner, interval timer, and streak engine
  • Hydration, sleep consistency, weight history, and milestone badges
  • Regular & Premium membership tiers with exportable CSV and PDF reports
